# Cyber-Cop / Corporation — Atlas 41

**[Русский](#по-русски) | [English](#english)**

## По-русски

[Открыть атлас](https://valetos2.github.io/cyber-cop-atlas/) · [Скачать полный архив](https://valetos2.github.io/cyber-cop-atlas/downloads/Cyber-Cop_Atlas41_full.zip)

Интерактивный атлас модификации Cyber-Cop v37 для Sega Mega Drive / Genesis: 32 карты кампаний Original и Amiga Mission Disk. Русская и английская версии работают без интернета; для запуска откройте соответствующий HTML из распакованного архива. ZIP также содержит превью в PNG, JSON и CSV.

Atlas 41 добавляет пять предметов из v37, счётчики на этажах, отдельные превью объектов, делящих клетку, и новый кадр лазера. Выбранный язык подсвечивается.

## English

[Open the atlas](https://valetos2.github.io/cyber-cop-atlas/) · [Download the full archive](https://valetos2.github.io/cyber-cop-atlas/downloads/Cyber-Cop_Atlas41_full.zip)

The interactive atlas for the Cyber-Cop v37 Sega Mega Drive / Genesis mod covers all 32 maps of the Original and Amiga Mission Disk campaigns. Both language editions work offline. Extract the ZIP and open either HTML file; the archive also includes PNG previews, JSON and CSV.

Atlas 41 adds the five v37 pickups, floor pickup counts, separate previews for stacked objects, and an updated laser image. The selected language is highlighted.

## Publishing

GitHub Actions publishes the atlas from the standalone ZIP in this repository. The site root stays unchanged so the QR code in the game still works. Generator sources are in the [mod repository](https://github.com/Valetos2/Cyber-Cop-Genesis-mod/tree/wip/atlas39).

This is an unofficial fan atlas. Rights to the original game assets remain with their respective holders.
